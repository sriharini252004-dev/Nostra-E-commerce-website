🛍️ Nostra E-Commerce Website

A modern and responsive Nostra E-Commerce Website built using HTML5, CSS3, and JavaScript. The project features a clean UI, responsive design, product collections, and interactive elements for a smooth shopping experience.

✨ Features

- Clean and modern user interface
- Fully responsive design
- Home page with attractive banner
- New Arrivals section
- Most Wanted products
- Product collection section
- Search functionality
- Responsive navigation menu
- Interactive UI elements
- Mobile-friendly layout

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
